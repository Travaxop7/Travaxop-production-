# TRAVAXOP - Artist Cloud Studio

## 📱 Overview

A professional, Spotify-inspired web application for **TRAVAXOP** - a music producer and composer dedicated to the Phonk genre. This website showcases original productions, remixes, and provides a complete artist portfolio experience.

## 🎨 Features

✅ **Dark Theme UI** - Professional Spotify-inspired black & red color scheme  
✅ **Track Management** - Browse and play popular tracks  
✅ **Artist Profile** - Complete bio and social media integration  
✅ **Audio Upload** - Add new tracks to the catalog  
✅ **Player Controls** - Interactive music player  
✅ **Responsive Design** - Works seamlessly on desktop and mobile  
✅ **YouTube Integration** - Direct links to music videos

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Travaxop7/Travaxop-production-.git
   cd Travaxop-production-
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
   ```bash
   python -m http.server 8000
   # Then visit: http://localhost:8000
   ```

- Click "+Upload Audio" in the sidebar
- Enter track title
- New tracks appear in the Popular Tracks list
